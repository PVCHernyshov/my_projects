## Проекты

### calculator
Консольный калькулятор с четырьмя арифметическими операциями.

**Технологии:** C, stdio.h  
**Сборка:** `gcc calculator.c -o calculator`

---

### matrix_static
Работа с двумерным массивом фиксированного размера (до 100x100). Ввод, вывод, поиск максимума.

**Технологии:** C, статический массив  
**Сборка:** `gcc find_max_static.c -o matrix_static`

---

### matrix_dynamic
Создание матрицы с динамическим выделением памяти (`malloc`, `calloc`, `free`). Автоматическое выравнивание столбцов.

**Технологии:** C, динамическая память, math.h (log10)  
**Сборка:** `gcc input_dynamic_flat.c -o matrix_dynamic -lm`

---

### matrix_circus
Программа для работы с матрицами: безопасный ввод через `strtol` с проверкой `errno` и `endptr`, поиск минимума и максимума, форматированный вывод.

**Технологии:** C, динамическая память, Makefile  
**Сборка:** `make` (в папке matrix_circus)

---

## Сборка

- Для проектов без Makefile используйте команды, указанные выше.
- Для `matrix_circus` перейдите в папку и выполните `make`.
- Все проекты компилируются с флагами `-Wall -Wextra -Werror -std=c11`.
