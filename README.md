## Проекты на C

### 1. Транспонирование матрицы и поиск максимума (`transpose_static.c`)

Программа для ввода квадратной матрицы (статический массив до 100x100), её вывода, транспонирования и поиска максимального элемента.

**Возможности:**
- Ввод матрицы фиксированного размера
- Проверка условия для транспонирования (матрица должна быть квадратной)
- Поиск максимального элемента и его координат (строка, столбец)
- Аккуратный вывод с форматированием

**Пример работы:**

Ввод:
```
3 3
1 2 3
4 5 6
7 8 9
```

Вывод:
```
1 2 3
4 5 6
7 8 9

1 4 7
2 5 8
3 6 9

Val = 9
r = 2 c = 2
```

**Запуск:**
```bash
gcc -Wall -Wextra -Werror transpose_static.c -o transpose
./transpose
```

### 2. Обработка матриц (`input_dynamic_falt.c`)

Программа для ввода прямоугольной матрицы и её вывода с автоматическим выравниванием столбцов.

**Возможности:**
- Динамическое выделение памяти (malloc)
- Поиск минимального и максимального элементов для расчёта ширины вывода
- Автоматическое выравнивание столбцов с помощью log10
- Корректная обработка ошибок ввода (вывод n/a)

**Пример работы:**

Ввод:
```
3 3
1 -500 3000
-42 7 100
-9999 20 5
```

Вывод:
```
    1  -500  3000
  -42     7   100
-9999    20     5
```

**Запуск:**
```bash
gcc -Wall -Wextra -Werror -std=c11 input_dynamic_falt.c -o matrix -lm
./matrix
```

### 3. Консольный калькулятор (`calculator.c`)

Простой калькулятор с четырьмя арифметическими операциями.

**Особенности:**
- Защита от деления на ноль
- Обработка ошибок ввода
- Возможность повторных вычислений

**Запуск:**
```bash
gcc calculator.c -o calc
./calc
```
