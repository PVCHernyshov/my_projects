## Проекты на C

### 1. Обработка матриц (input_dynamic_falt.c)
Программа для ввода прямоугольной матрицы и её вывода с автоматическим выравниванием столбцов.

Возможности:
- Динамическое выделение памяти (malloc)
- Поиск минимального и максимального элементов для расчёта ширины вывода
- Автоматическое выравнивание столбцов с помощью log10
- Корректная обработка ошибок ввода (вывод n/a)

Пример работы (наглядно показывает выравнивание):
Ввод: 
3 3
1 -500 3000 -42 7 100 -9999 20 5

Вывод:
    1  -500  3000
  -42     7   100
-9999    20     5

Запуск:
gcc -Wall -Wextra -Werror -std=c11 input_dynamic_falt.c -o matrix -lm
./matrix

### 2. Консольный калькулятор (calculator.c)
Простой калькулятор с четырьмя арифметическими операциями.

Особенности:
- Защита от деления на ноль
- Обработка ошибок ввода
- Возможность повторных вычислений

Запуск:
gcc calculator.c -o calc
./calc
